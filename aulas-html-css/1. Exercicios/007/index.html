Principais formatações

Negrito / Destaque

Nesta frase, temos um termo em negrito usando a tag b (não semântica ~ apenas forma).

Nesta frase, temos um termo em destaque usando a tag STRONG (semântica ~ possui significado).

Itálico / Ênfase

Nesta frase, temos um termo em itálico usando a tag i (não semântica).

Nesta frase, temos um termo em ênfase usando a tag EM (semântica).

As tags B e I, com o tempo, se tornarão obsoletas. Evitar usar!

Texto marcado

Podemos criar também um texto marcado usando a tag MARK.

E no outro parágrafo, temos outro texto marcado no final.

É possível também criar várias marcações com a mesma cor. Iremos criar em head uma tag style em seguida de um seletor para mark, chamado de background-color.

Texto grande

Antigamente, utilizávamos a tag <big> para aumentar visualmente o tamanho do texto. Mas, esta tag se tornou obsoleta e não deve mais ser utilizada. O correto é criar uma classe em CSS.
